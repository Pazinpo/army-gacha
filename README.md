# 군대 뽑기 시뮬레이터

신체등급 → 군종 → 자대·보직 → 부대 분위기 → 간부 운까지 전부 뽑기로 정해지는 군 생활 시뮬레이션 웹 게임.
랜덤으로 정해지는 군 생활을 시간 순서대로 살아 보며 중간중간 결정을 내리고, 마지막에 전역증과 결과를 받는 웹 게임입니다.

## 실행

빌드 과정이 없는 정적 사이트입니다.

- `index.html` 을 브라우저로 열면 바로 실행됩니다.
- 또는 이 폴더에서 `python -m http.server 8765` 후 `http://127.0.0.1:8765` 접속.

## 구조

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대(타이틀·게임·엔딩·뽑기 오버레이·도감) |
| `css/style.css` | 스타일 (모바일 대응 포함) |
| `js/data.js` | 콘텐츠: 신체등급, 군종, 보직, 부대 분위기, 간부 운, 훈련소·일반 이벤트, 칭호, 용어집 |
| `js/art.js` | 192×108 픽셀 씬 렌더러 (캔버스, 계절·야간·눈·비·안개 오버레이) |
| `js/game.js` | 엔진: 뽑기 연출, 시간 진행, 이벤트, 저장/이어하기, 엔딩, 도감 |

## 콘텐츠 추가하기

- 이벤트: `js/data.js` 의 `EVENTS` 배열에 객체를 추가합니다.
  `r`(계급 범위 0~3), `b`(군종), `tags`(보직 태그 중 하나), `season`, `need`(조건 함수), `w`(가중치)로 등장 조건을 걸고,
  `auto: true` 면 선택 없는 일상 이벤트, 아니면 `choices` 로 선택지를 만듭니다.
  선택지에 `p`(성공 확률 함수)와 `win`/`lose` 를 주면 도전형이 됩니다.
- 훈련소 이벤트는 `TRAIN_EVENTS` (`order` 순서대로 훈련 주차에 분배).
- 보직: `UNITS` 에 추가 (`br` 군종, `w` 확률 가중치, `g` 꿀지수 -2~+2, `leaveBonus` 보상휴가).
- 밸런스: `js/game.js` 의 `BASE_DRIFT`, `REVERT`, `computeDrift()` 와 `calcScore()`.
- 사고·징계: 선택 결과에 `inc: 1`을 주면 사고가 쌓이고(`S.flags.incidents`), 3번 쌓이면 중대장 면담 → 군기교육 → (마음이 바닥이거나 사고가 이어지면) 군 병원 의무조사로 이어집니다. 선택지에 `endEarly: 'medical'`을 주면 조기 전역(의가사) 엔딩이 됩니다.
- 개발용 훅: `window.__fastSim`(대기 시간 0), `window.__forceBranch`/`__forceFit`(군종·신체등급 고정), `window.__ag`(상태 확인)를 시뮬레이션 테스트에 썼습니다.

## 게임 규칙 메모

- 뽑기는 횟수 제한 없이 다시 돌릴 수 있습니다. 대신 엔딩에 "몇 번 다시 돌렸는지"가 남습니다.
- 자동 결정은 이벤트 선택지만 대신 골라 줍니다. 뽑기(신체등급·군종·자대 배치 등)는 항상 직접 누르고, 조기 전역 같은 큰 결정은 자동으로 고르지 않습니다. 새로 열면 항상 꺼진 상태입니다.
- 자대 배치 전에는 훈련병(사회복무는 교육생), 배치 뒤부터 이병입니다.
- 사고를 한 번 치면 또 사고를 치기 쉬워집니다(사고 이벤트 가중치 상승). 면담 → 군기교육 → 의무조사 순으로 이어질 수 있고, 마음이 바닥인 경우에도 의무조사가 열립니다. 의가사 전역은 계속 복무(치료 포함)하는 선택지와 함께 나옵니다.

- 탈영(군무이탈) 라인: 마음이 바닥이거나 곰신과 이별했거나 사고가 이어진 상태로 휴가를 나가면 "휴가 마지막 날 밤"이 열릴 수 있습니다. 털어놓기·상담(1303)·복귀 중 하나를 고르면 이어 가고, "복귀하지 않는다"를 고르면 "미복귀 이틀째"가 나옵니다. 거기서 자진 복귀하면 징계 후 이어지고, 끝까지 버티면 **영창행(군무이탈) 엔딩**으로 끝납니다. 동기가 복귀하지 않는 이벤트도 따로 있습니다. 위험한 선택지는 "무거운 선택"으로 표시되고, 자동 결정은 고르지 않습니다.

## 자료 조사와 반영 내용

군 생활 디테일은 웹 검색으로 확인한 내용을 바탕으로 합니다. 출처의 상당수가 나무위키 등 커뮤니티 문서와 언론 보도이고, **병무청·국방부 공식 자료로 직접 검증한 것은 아닙니다.** 문장은 그대로 옮기지 않고 사실만 정리해 게임용으로 다시 썼습니다.

반영한 것:
- 복무기간: 육군·해병 18개월, 해군 20개월, 공군·사회복무 21개월.
- 병사 월급: 이병 75 / 일병 90 / 상병 120 / 병장 150만원 (2026년 보도), 장병내일준비적금 정부 매칭 월 최대 55만원.
- 훈련소: 육군 5주(1주 정신전력·제식, 2주 영점사격, 3주 수류탄, 4주 각개전투와 20km 행군, 5주 수료), 해군·공군 5주, 해병 6주(극기주 행군 후 빨간 명찰), 보충역 3주, 훈련병 휴대전화 주말 1시간(2023.7~).
- 자대 배치: 육군은 퇴소 주 목요일 난수 추첨, 공군은 성적순 지망, 해군·해병은 후반기 교육 뒤 실무 배치.
- 휴가: 정기휴가 육군·해병 24일 / 해군 27일 / 공군 28일, 신병위로휴가 3박 4일(입대 약 100일 무렵, 정기휴가와 별개), 포상휴가 상한 육군 16·해군 17·공군 18일, GOP 보상휴가, 말년휴가는 한 번에 15일 이내.
- 일과: 기상 06:30, 아침점호(복무신조·도수체조), 저녁점호 21시 이후, 불침번 22시~06:30(초번초·말번초·말전초), 평일 휴대전화 18~21시.
- 훈련·작업: 유격 4박 5일(입소 행군, PT체조, 참호격투, 복귀 행군), 혹한기 훈련(A형 텐트·핫팩·얼어붙은 전투화), 제설·제초·대민지원, 특급전사(포상휴가 3~5일·조기진급).
- 군종별: 카투사(어학성적 통과 후 전산 추첨, 약 10:1, 교육대·홀드 오버·패스폼·시카), 해군(함정 vs 육상, 앵카 서약, 15분 전 문화), 공군(일과제·독서실·6주 정기외박), 해병(기수 문화), 사회복무(근무지 직접 선택/자동 배치, 꿀무지·헬무지, 재지정).
- 계급별 분위기: 일병이 가장 고된 시기, 일꺾·상꺾, 상병이 가장 빨리 가는 시기, 말출, 말년의 열외, 전역신고 문구, 전역 후 예비군 약 8년·민방위 만 40세까지.

확인이 덜 됐거나 가정한 것:
- 사회복무·상근예비역·카투사의 연가 일수는 육군(24일)과 같다고 가정한 값입니다.
- 평일 외출·주말 외출·외박 횟수는 자료마다 달라 수치를 쓰지 않았습니다.
- 병 진급누락(자동진급 폐지)은 2025년 6월에 잠정 보류됐다는 보도까지만 확인했습니다. 이벤트에는 "제도가 바뀌는 중"이라고만 표시합니다.
- 카투사 교육 기간은 자료마다 달라 기초군사훈련 5주 + 교육대 약 3주로 잡았습니다.
- 상근예비역은 소집 규모가 줄고 있다는 서술이 있어 현행 선발 방식을 확인하지 못했습니다.
- 병 징계의 영창은 2020년 8월에 폐지되고 군기교육으로 바뀌었다고 알려져 있습니다(법률 칼럼·언론 기준). "영창행" 엔딩은 속어를 빌린 이름이고, 실제 군무이탈은 형사처벌 절차로 이어집니다. 군기교육 기간만큼 복무기간에 산입되지 않아 전역이 밀린다는 설명이 있어 2주로 가정했습니다.
- 탈영 사유별 통계와 구체적 형량은 공식 자료를 찾지 못해 게임에 숫자를 쓰지 않았습니다.
- 신체등급 확률, 보직 확률, 꿀지수, 스탯 변화량은 모두 게임용 값입니다.
